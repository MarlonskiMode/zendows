## Major
### Anomaly Release & Signing
Zendows now ships under the `com.marlonskimode.zendows` bundle ID, signed with Anomaly's Developer ID
certificate and published through `example.invalid/zendows-updates`. Existing `0.3.0` users will be
prompted once to grant Accessibility access again for the new bundle ID (your config, rules, and
workspace state stay untouched).
## Improvements
- Upgraded the Accessibility onboarding guide to match Hex's macOS polish: flying app-tile handoff into System Settings, cold-launch and cross-Space deep-link retries, frontmost-only guide visibility, macOS 27 list naming, 120 ms grant polling, and automatic return to Zendows once granted.
